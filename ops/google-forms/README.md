# Google フォーム（運営用）

このフォルダには、運営で使う Google フォームを生成する Google Apps Script を置く。
フォーム本体は Google 側にあるので、ここで管理するのは「どんな設問だったか」の元データ。

## 作り方

1. https://script.google.com/ で新規プロジェクトを作成
2. 対象の `.gs` の中身を `Code.gs` に貼り付けて保存
3. 生成関数を実行（初回のみ権限の承認が必要）
4. 実行ログに出る **編集用URL / 回答用URL / 回答スプレッドシートURL** を控える

作り直すときは再実行すれば新しいフォームが増える（既存フォームは書き換えない）。
設問を直したいときは、Google フォーム側で直したあと **このファイルにも同じ修正を反映する**
（次に作り直したとき内容が戻ってしまうため）。

## 一覧

| ファイル | フォーム | 用途 |
| --- | --- | --- |
| `staff-preday-checklist.gs` | 【スタッフ用】ツアー前日チェックリスト | ツアー前日 18:00 までにスタッフが記入。基本情報 → プラン別（A/B/C 分岐）→ 食事 → 機材・車両 → 最終確認・申し送り |

### staff-preday-checklist.gs の構成

- ページ1 基本情報（記入者・実施日・人数・宿泊先と配達時間・集合・前日連絡・**プラン選択＝分岐**）
- ページ2〜4 プランA / B / C の準備チェック（選んだプランのみ表示 → 終わると「食事」へ合流）
- ページ5 食事（朝食お茶漬け・夕食ヴィーガン鍋・ランチ・アレルギー対応・配達段取り）
- ページ6 機材・車両（e-bike 台数／充電／点検／サイズ、雨天時の車両、救急箱ほか）
- ページ7 最終確認・申し送り（天気・雨天判断・緊急連絡先・Square 決済・役割分担）

チェック項目は「完了 / 未完了 / 該当なし」のグリッド設問で、各行が必須。
「未完了」があった場合は最後の申し送り欄に内容と対応予定を書く運用。
